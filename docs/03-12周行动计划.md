# 12 周行动计划

> 假设每周投入 8–10 小时；如果每周只有 5 小时，把周次乘以 1.6–2，整体拉长到 18–20 周。
> 原则：每周必须有一个能运行、能给别人演示的产物。

## 一、每周时间分配

| 类型 | 时间 | 说明 |
|---|---|---|
| 读概念/文档 | 2 h | 先建立框架，不要陷进细节 |
| 写代码 | 5 h | 主体时间，必须动手 |
| 查错/修环境 | 1 h | RCP 的配置问题很多，留出缓冲 |
| 笔记/复盘 | 1 h | 记录踩坑和“为什么” |
| 演示/整理 | 1 h | 录屏或截图，形成阶段成果 |

## 二、周计划

### 第 1 周：环境 + Java/Eclipse 基本功

**任务**

- [ ] 安装 JDK 21、Eclipse RCP 2026-06、7-Zip；配置 `eclipse.ini`、UTF-8、Installed JREs。
- [ ] 完成 [06-第一次动手-Hello插件](06-第一次动手-Hello插件.md)：新建 `com.example.hello`，运行第二个 Eclipse，用 Plug-in Spy 验证。
- [ ] 复习 Java：泛型、集合、Lambda/Stream、异常、IO/NIO、多线程。
- [ ] 复习 Java 17/21 特性：record、sealed、模式匹配、文本块、var。
- [ ] 用 Eclipse 建 Maven 项目，写 console 任务管理，加 JUnit 5 测试。
- [ ] 学 Git：commit、branch、tag、`.gitignore`。
- [ ] 初始化 `D:\git\rcp-demos`，提交并打 `stage-0`。

**产出**：可运行、可测试、可提交的 Java 项目。
**复盘**：`JAVA_HOME`、PATH、`-vm`、BREE 四者关系是否讲得清？

### 第 2 周：OSGi 与第一个插件

**任务**

- [ ] 学 Bundle、MANIFEST.MF 关键头、Bundle 生命周期。
- [ ] 学 `Require-Bundle` vs `Import-Package` vs `Export-Package`。
- [ ] 学扩展点、`plugin.xml`、registry、lazy loading。
- [ ] 新建 Plug-in Project `com.example.hello`。
- [ ] 用 `org.eclipse.ui.views` 贡献视图。
- [ ] 用 `org.eclipse.ui.menus` 贡献菜单和命令。
- [ ] 用 Plug-in Spy 查看视图来源。
- [ ] 打 `stage-1a`。

**产出**：能在运行时 Eclipse 中打开自己的视图、点击自己的菜单。
