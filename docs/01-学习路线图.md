# Eclipse RCP 学习路线图

> 目标：从“会 Java”到“能独立交付一个 Eclipse RCP 桌面产品”
> 建议周期：12 周，约 120 小时；每周 8–10 小时可跟上，每周 5 小时则延长到 18–20 周。

## 一、先建立正确的心智模型

Eclipse RCP 不是普通类库，而是“可组装的桌面应用平台”。学习时始终问自己四个问题：

1. 这个功能是一个 **Bundle/Plugin** 吗？
2. 它通过哪个 **扩展点（Extension Point）** 接入平台？
3. 它的 UI 是 **SWT/JFace** 还是 **e4 应用模型** 驱动的？
4. 最终如何被 **Feature/Product/p2** 组装和发布？

四层能力模型：

```text
第 4 层  产品化      Feature / Product / p2 / Tycho / 安装包
第 3 层  UI          SWT / JFace / e4 模型 / CSS / 数据绑定
第 2 层  平台机制    OSGi / Bundle / 扩展点 / PDE / 目标平台
第 1 层  Java 基础   Java 21 / 集合 / 并发 / Maven / Git / 调试
```

常见的失败路径：

- 只会拖控件，不懂 Bundle 和扩展点 → 换一个 Eclipse 版本就不会跑。
- 只学 3.x 的 `ViewPart` / `ApplicationWorkbenchAdvisor` → 看不懂现代 e4 项目。
- 一上来就学 EMF/Xtext → 基础不牢，排错困难。
- 不做产品化 → 代码能跑，但交付不了。

## 二、最终能力目标

学完你应能：

- [ ] 用 PDE 创建多插件工程，解释 `MANIFEST.MF` 的每个关键头。
- [ ] 区分 `Require-Bundle` 与 `Import-Package`，并能排查“包找不到”。
- [ ] 用 SWT 写出布局自适应、资源正确释放、UI 线程安全的界面。
- [ ] 用 JFace Viewer 实现表格/树的 CRUD、排序、过滤、编辑。
- [ ] 用纯 e4 模型 + DI + 命令/处理器 + 事件总线组织应用。
- [ ] 用 CSS 定制主题，用 CSS Spy 调试样式。
- [ ] 用 Feature/Product/p2 打包，并在干净机器上运行。
- [ ] 用 Tycho 无 GUI 构建，接入 CI。
- [ ] 用 JUnit 5 + SWTBot 做逻辑与 UI 测试。
- [ ] 读懂 3.x 老项目，知道如何迁移到 e4。

## 三、阶段路线总览

| 阶段 | 周次 | 主题 | 关键产出 |
|---|---|---|---|
| 0 | 第 1 周 | Java、Eclipse、Git、Maven 基本功 | 可调试、可测试的 Java 小项目 |
| 1 | 第 2–3 周 | OSGi、插件、扩展点、PDE、目标平台 | 贡献视图/菜单/首选项的插件 |
| 2 | 第 3–4 周 | SWT 控件、布局、事件、绘图、线程 | 布局自适应的表单与表格 |
| 3 | 第 4–5 周 | JFace Viewer、向导、首选项、数据绑定 | CRUD 任务列表 |
| 4 | 第 5–7 周 | e4 应用模型、依赖注入、命令、事件、CSS | 纯 e4 双 Part 应用 |
| 5 | 第 7–9 周 | Feature、Product、p2、Tycho、安装包 | 可安装的产品 zip |

| Capstone | 第 11–12 周+ | 综合项目 | 完整产品 + 文档 + 演示 |

## 阶段 0：Java 与 Eclipse 基本功（第 1 周）

**目标**：能用 Eclipse 熟练地写、调试、测试、提交一个 Java 项目。

### 知识点

- Java 语法复习：泛型、集合、Lambda/Stream、异常、IO/NIO、多线程基础。
- Java 17/21 常用特性：`record`、`sealed`、模式匹配、文本块、`var`。
- Eclipse 工作台：Workspace/Project、Perspective/View/Editor、Run/Debug、断点、变量/表达式。
- 编码：UTF-8；JDK 配置；Maven 项目导入。
- Git：clone/commit/branch/tag；`.gitignore`。
- Maven：`pom.xml`、生命周期、依赖作用域、多模块。

### 练习

- 用 Java 21 写一个 console 版“任务管理”：增删改查 + JSON 文件持久化 + JUnit 5 测试。
- 在 Eclipse 中打断点调试，查看调用栈和变量。
- 建 Git 仓库，打 `stage-0` 标签。

### 验收

- 能独立解决 “Unsupported class file major version” 这类 JDK 不匹配问题。
- 能说清 `JAVA_HOME`、PATH、Eclipse `-vm`、项目 BREE 四者关系。

### 资料

- vogella Eclipse IDE Tutorial：https://www.vogella.com/tutorials/Eclipse/article.html
- Dev.java / Oracle Java 21 文档

## 阶段 1：OSGi、插件与 PDE（第 2–3 周）

**目标**：理解 Eclipse 的模块化和扩展机制，能写一个向 IDE 贡献视图/菜单的插件。

### 知识点

- OSGi Bundle：
  - `Bundle-SymbolicName`、`Bundle-Version`
  - `Bundle-RequiredExecutionEnvironment`（BREE）
  - `Bundle-Activator`、`Bundle-ActivationPolicy: lazy`
- 依赖关系：
  - `Require-Bundle` vs `Import-Package` vs `Export-Package`
  - 版本范围、可选依赖（`resolution:=optional`）
- Bundle 生命周期：INSTALLED → RESOLVED → STARTING → ACTIVE → STOPPING → UNINSTALLED。
- Fragment、Feature、Product 的区别。
- 扩展点：`plugin.xml`、`extension`、`extension point`、registry、lazy loading。
- PDE：
  - Plug-in Editor 的 Overview / Dependencies / Runtime / Extensions / Build 页
  - Target Platform：Running Platform vs Target Definition（`.target`）
  - 启动配置：`Eclipse Application`
- 3.x 与 e4：
  - `org.eclipse.ui` 兼容层、`IWorkbench`、`ViewPart`
  - `ApplicationWorkbenchAdvisor`、`WorkbenchWindowAdvisor`
- 调试工具：Plug-in Spy、PDE Error Log、`workspace/.metadata/.log`。

### 练习

- 新建插件 `com.example.hello`，通过 `org.eclipse.ui.views` 贡献一个视图。
- 通过 `org.eclipse.ui.menus` 贡献菜单项，点击弹出 `MessageDialog`。
- 通过 `org.eclipse.ui.preferencePages` 贡献首选项页。
- 用 Plug-in Spy 查看当前选中对象来自哪个插件。
- 建一个 `.target` 文件，指向 2026-06 更新站点。

### 验收

- 能解释为什么“编译通过但运行时 `NoClassDefFoundError`”通常是 `Import-Package` 或目标平台问题。
- 能独立新建 target definition 并设为活动目标平台。
- 能说清 Bundle、Feature、Product 三者的职责。

### 资料

- Eclipse PDE Guide（官方 Help：https://help.eclipse.org/latest/index.jsp）
- vogella “Eclipse Plug-in” / “OSGi” tutorials
- 《Eclipse Rich Client Platform》（3.x 经典，注意版本差异）

## 阶段 2：SWT（第 3–4 周）

**目标**：不依赖可视化设计器，手写布局正确、无资源泄漏的 SWT 界面。

### 知识点

- `Display`、`Shell`、`Composite`；SWT 单线程 UI 模型。
- 布局：
  - `FillLayout`、`RowLayout`
  - `GridLayout` + `GridData`
  - `FormLayout`
  - `MigLayout`（第三方，可选）
- 常用控件：
  - `Label`、`Text`、`Button`、`Combo`、`List`
  - `Table`、`Tree`、`TabFolder`/`CTabFolder`
  - `SashForm`、`ToolBar`、`CoolBar`
  - `StyledText`、`Browser`、`Canvas`
- 事件：`SelectionListener`、`ModifyListener`、`KeyListener`、`MouseListener`、`FocusListener`。
- 资源管理：`Color`、`Font`、`Image`、`GC` 的创建与 `dispose()`；`JFaceResources`。
- 绘图：`GC`、`Canvas`、双缓冲、重绘。
- 对话框：`MessageDialog`、`FileDialog`、`DirectoryDialog`、`ColorDialog`、`FontDialog`。
- 线程：
  - `Display.asyncExec` / `syncExec`
  - 后台任务用 `Job` / `UIJob`
  - 禁止在非 UI 线程操作控件
- 高 DPI、国际化字符串、快捷键。

### 练习

- 设备信息录入表单：`GridLayout`，窗口缩放不破版。
- 带排序/过滤的表格。
- 图片查看器：`Canvas` + `GC` 绘制，支持缩放。
- 用 `Job` 模拟耗时任务，显示进度且不卡 UI。

### 验收

- 窗口从 800×600 拉到 1920×1080，布局仍正确。
- 用 VisualVM 或代码审查确认无 SWT 资源泄漏。
- 能解释 `Invalid thread access` 的原因和修复方式。
- 能说清 `GridData` 中 `horizontalAlignment`、`grabExcessHorizontalSpace`、`widthHint` 的组合效果。

### 资料

- SWT Snippets：https://www.eclipse.org/swt/snippets/（逐个跑，最有效）
- vogella SWT tutorial
- Eclipse SWT API docs

## 阶段 3：JFace（第 4–5 周）

**目标**：用 Viewer 和 JFace 框架写业务界面，而不是直接操作 `Table`。

### 知识点

- Viewer 体系：
  - `TableViewer`、`TreeViewer`、`ListViewer`、`ComboViewer`
  - `TableViewerColumn`
- Provider：
  - `IStructuredContentProvider`
  - `ITableLabelProvider`、`CellLabelProvider`
  - `ViewerFilter`、`ViewerSorter`、`EditingSupport`
- JFace Action、`ActionGroup`、上下文菜单。
- 向导：`Wizard`、`WizardPage`、`WizardDialog`。
- 首选项：`PreferencePage`、`PreferenceInitializer`、`IEclipsePreferences`。
- 对话框：`TitleAreaDialog`、`Dialog`、`InputDialog`。
- 数据绑定：
  - `DataBindingContext`
  - `IObservableValue`、`WritableValue`
  - `UpdateValueStrategy`、验证
- 图片/字体：`ImageDescriptor`、`JFaceResources`。
- 进度：`ProgressMonitorDialog`、`IRunnableWithProgress`。

### 练习

- 任务管理 CRUD：`TableViewer` + 搜索框 + 排序 + 双击编辑。
- 新增任务向导（多页）。
- 首选项页保存过滤/排序设置。
- 用数据绑定把表单字段绑定到模型并做校验。

### 验收

- 业务模型与 UI 解耦，Viewer 通过 ContentProvider 取数。
- 首选项重启后仍生效。
- 表格支持排序、过滤、编辑，且不直接 `new TableItem`。

### 资料

- vogella JFace tutorials
- Eclipse JFace docs
- SWT/JFace snippets

## 阶段 4：e4 应用模型与依赖注入（第 5–7 周）

**目标**：用纯 e4 方式组织应用，理解现代 RCP 的核心。

### 知识点

- e4 模型元素：
  - `MApplication`、`MWindow`、`MPerspective`
  - `MPart`、`MPartStack`
  - `MMenu`、`MHandledMenuItem`、`MToolBar`、`MTrimBar`
- `Application.e4xmi`、`fragment.e4xmi`、模型编辑器、`EModelService`。
- 依赖注入：
  - `IEclipseContext` 层级与查找顺序
  - `@Inject`、`@Named`、`@Optional`
  - `@Preference`、`@EventTopic`、`@Creatable`、`@Singleton`
- 生命周期：`@PostConstruct`、`@PreDestroy`、`@Focus`、`@Perspective`、`@PartStack`。
- 命令与处理器：
  - `@Execute`、`@CanExecute`、`@Enabled`、`@Visible`
  - core expression、handler 优先级
- 服务：
  - `EPartService`、`ESelectionService`
  - `EEventBroker`、`ECommandService`、`EHandlerService`
  - `MApplication`
- 事件总线：`IEventBroker` 发布/订阅；与 selection service 的区别。
- CSS：主题扩展、`e4_default_win.css`、选择器、CSS Spy。
- 3.x 兼容层：`ApplicationWorkbenchAdvisor`、`WorkbenchWindowAdvisor`、`ViewPart`、`HandlerUtil`；知道何时必须用。

### 练习

- 用 “Eclipse 4 RCP Application” 向导建纯 e4 应用。
- 两个 Part（列表 + 详情），菜单/工具栏命令控制增删。
- 用 DI 注入一个共享的 `TaskService`。
- 用 `IEventBroker` 做 Part 间通信。
- 用 CSS 改主题色/字体，用 CSS Spy 定位选择器。

### 验收

- 不写 3.x advisor 也能跑起应用。
- 能解释 `@Inject` 在 context 层级中如何找到对象。
- 能写出 `@CanExecute` 随选择变化而启停的处理器。
- 能说清 Part、Perspective、Window、Application 的包含关系。

### 资料

- vogella Eclipse 4 RCP Tutorial：https://www.vogella.com/tutorials/EclipseRCP/article.html
- vogella《Eclipse Rich Client Platform》第 4 版（2025-12，Java 21）
- Eclipse e4：https://www.eclipse.org/e4/
- EclipseSource e4 教程系列（较老，但概念清晰）

## 阶段 5：产品化（第 7–9 周）

**目标**：把“能跑的工程”变成“能交付的产品”。

### 知识点

- Feature 工程：`feature.xml`、包含插件、版本。
- Product 配置：`.product`、application ID、branding（splash、图标、About、窗口图片）。
- p2：
  - metadata / artifact repository
  - category、update site
  - install/update
- 目标平台与构建：`.target`、`build.properties`、qualifier、版本号。
- PDE Export Wizard vs Tycho headless build。
- Tycho：
  - pomless
  - `eclipse-plugin` / `eclipse-feature` / `eclipse-repository` 打包类型
  - `tycho-p2-director-plugin`
  - `mvn clean verify`
- 运行环境：原生 launcher、捆绑 JRE（可选）、`eclipse.ini`、内存参数。
- 安装包：Inno Setup / MSI / zip。
- 自动更新：p2 update site、`-application org.eclipse.equinox.p2.director`。

### 练习

- 把任务管理应用拆成 `core` / `ui` / `feature` / `product` 四个工程。
- 导出产品，在另一台机器或虚拟机运行。
- 用 Tycho 构建出 zip，接入 GitHub Actions。
- 做一个 p2 update site，验证升级。

### 验收

- `mvn clean verify` 在干净环境成功。
- 产物在无 Eclipse 的机器上可启动。
- 改版本号后能通过 update site 升级。
- 能解释 product、feature、plugin 在 p2 中的关系。

### 资料

- Tycho 官方文档：https://github.com/eclipse-tycho/tycho
- vogella “Tycho” / “Eclipse RCP deployment” tutorials
- Eclipse p2 docs

## 阶段 6：测试与质量（第 9–10 周）

**目标**：让 RCP 项目具备可持续交付的质量保障。

### 知识点

- JUnit 5：纯逻辑测试、参数化、断言。
- 插件测试：`JUnit Plug-in Test`、target platform、测试 fragment。
- SWTBot：UI 自动化、`SWTWorkbenchBot`、控件查找、等待。
  - SWTBot 的 UI 测试通常基于 JUnit 4 Runner；纯逻辑测试用 JUnit 5，两者可以在同一工程中共存。
- Mockito / AssertJ。
- Tycho Surefire；JaCoCo 覆盖率。
- CI：GitHub Actions / Jenkins；无 GUI 构建；缓存。
- 静态分析：SpotBugs、Checkstyle、SonarQube（可选）。
- 日志：SLF4J + Logback/Log4j2 在 OSGi 中的配置。

### 练习

- 给 `TaskService` 写单元测试。
- 给“新增任务”流程写 SWTBot 冒烟测试。
- CI 每次 push 自动 `mvn verify`。

### 验收

- 测试可在命令行跑，不依赖手工点击。
- CI 失败能定位到具体插件/测试。
- 能解释为什么 RCP 的 UI 测试比普通 Swing 测试更容易不稳定，以及如何用等待策略解决。

### 资料

- SWTBot 官方 wiki
- Tycho Surefire docs
- JUnit 5 User Guide

## 阶段 7：进阶与方向选择（第 11–12 周及以后）

按工作方向选 1–2 个：

- **模型驱动**：EMF（`.ecore` / `.genmodel`）、EMF Edit、EMF Forms。
- **DSL/编辑器**：Xtext、自定义编辑器、语法高亮、内容辅助。
- **图形/可视化**：GEF/Draw2d、Zest、BIRT。
- **富客户端扩展**：JavaFX + e(fx)clipse、Nebula 控件。
- **Web 化**：RAP（把 RCP 跑到浏览器）。
- **老项目迁移**：3.x → e4、兼容层、增量迁移策略。
- **性能与稳定性**：UI 冻结排查、内存泄漏、启动优化、`SWT.VIRTUAL`、懒加载。
- **国际化/无障碍/帮助系统**：NLS、`org.eclipse.help`、键盘导航。

### 验收

- 能在一个真实/模拟项目中独立定位并解决一个平台级问题。
- 能写一份技术方案，说明为什么选某个扩展点/架构。

## 四、Capstone 项目：任务管理 RCP 应用

### 功能需求

- 任务 CRUD、分类/标签、优先级、截止日期。
- 列表 + 详情双 Part；搜索/过滤/排序。
- 新增/编辑向导；首选项（默认排序、主题）。
- JSON 导入/导出；SQLite 持久化（可选）。
- 菜单/工具栏/快捷键；`@CanExecute` 控制可用性。
- 中文/英文国际化；日志；About/帮助。
- 产品打包、p2 更新站点、Tycho 构建、SWTBot 冒烟测试。

### 技术要求

- 纯 e4 应用模型 + DI。
- `core` / `ui` / `feature` / `product` 分层。
- 至少 10 个 JUnit 测试 + 2 个 SWTBot 测试。
- Git 历史清晰，每个阶段有 tag。

### 交付物

- 源码仓库（含 README、构建说明）。
- 产品 zip（Windows x64）。
- CI 配置文件。
- 5–10 分钟演示视频/截图。
- 一页架构说明（模块图、扩展点、数据流）。

## 六、学习方法

1. **每个阶段一个可运行 demo**，不要只看不写。
2. **先跑通最小示例，再改**；RCP 配置问题比代码问题多。
3. **保存错误现场**：`.metadata/.log`、PDE Error Log、launch config、target platform 截图。
4. **读源码**：`org.eclipse.ui` 示例、e4 自带 demo、SWT snippets。
5. **写笔记**：每阶段一篇“我踩过的坑”，比抄教程有用。
6. **用 Git tag 固化阶段成果**，方便回退和对比。
