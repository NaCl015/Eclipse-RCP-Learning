## 一、版本决策

| Eclipse 版本 | 版本号 | IDE 运行要求 | 说明 |

| 2026-09 | 4.41 | Java 25 | 最新，但不适合本机“统一 Java 21”的目标 |
| **2026-06** | **4.40** | **Java 21** | **本次选择**；平台 BREE 为 JavaSE-21 |
| 2026-03 | 4.39 | Java 21 | 可选 |

结论：

- 本机主环境：**Eclipse 2026-06（4.40）+ Temurin JDK 21 LTS**
- 保留 JDK 17：用于兼容旧项目/旧目标平台
- 如果以后要上 2026-09，再单独安装 JDK 25，不要影响当前环境

### 3.1 为什么选 RCP 包

`Eclipse IDE for RCP and RAP Developers` 自带：

- Eclipse Platform / Equinox（OSGi 运行时）
- JDT（Java 开发工具）
- **PDE（Plug-in Development Environment）**
- e4 应用模型编辑器、PDE Spy
- Git、Maven、Gradle、XML 编辑器

只装 Java 包还需要手动补 PDE 和 e4 工具，容易漏。

### 3.2 为什么还要单独装 JDK 21

Eclipse 安装包虽然自带 JRE，但以下场景需要完整 JDK：

- 命令行 `mvn clean verify`（Tycho 构建）
- 以指定 JDK 启动/调试独立 RCP 产品
- Maven toolchains 指定编译 JDK
- `jarsigner`、`jlink`、`jpackage` 等工具

## 六、安装与配置步骤

### 6.1 安装 JDK 21

本次使用 zip 版（不需要管理员权限）：

1. 下载 `OpenJDK21U-jdk_x64_windows_hotspot_21.0.13_9.zip`
2. 解压到临时目录
3. 把 `jdk-21.0.13+9` 里面的内容移动到 `D:\Java21`
4. 验证：

```powershell
D:\Java21\bin\java -version
D:\Java21\bin\javac -version
```

期望输出：

```text
openjdk version "21.0.13" 2026-10-20 LTS
OpenJDK Runtime Environment Temurin-21.0.13+9
javac 21.0.13
```

### 6.2 环境变量策略

本机有两个限制：

- 当前用户不是管理员，不能改“系统级”环境变量。
- 系统 PATH 中已有 Oracle `javapath` 和 `D:\Java17\bin`，所以新终端里直接敲 `java` 可能仍显示 17。

本次采取的策略：

- 用户级 `JAVA_HOME=D:\Java21`（已设置）
- `D:\tools` 加入用户 PATH（已设置）
- 用户级 `HOME=C:\Users\薰`（已设置，供 EGit/Git 使用）
- 提供 `mvn21.cmd`，强制用 JDK 21 运行 Maven
- Eclipse 通过 `eclipse.ini` 的 `-vm` 固定用 JDK 21

检查：

```powershell
# 直接看 JDK 21
D:\Java21\bin\java -version

# 看 Maven 用的 JDK
D:\tools\mvn21.cmd -v

# 看当前终端 java 来自哪里（可能仍是 17，这是正常的）
where.exe java
```

如果希望新终端里 `java` 默认就是 21，需要用管理员权限调整系统 PATH，把 `D:\Java21\bin` 放到 Oracle `javapath` 之前。学习 RCP 不强制要求这样做。

### 6.3 解压 Eclipse

1. 下载 `eclipse-rcp-2026-06-R-win32-x86_64.zip`（约 550 MB）
2. 用 7-Zip 解压
3. 确保 `eclipse.exe` 直接位于 `D:\eclipse\rcp-2026-06\` 下，而不是 `...\rcp-2026-06\eclipse\eclipse.exe`
4. 不要装到 `C:\Program Files`：权限、路径空格、升级都会更麻烦

### 6.4 配置 eclipse.ini

打开 `D:\eclipse\rcp-2026-06\eclipse.ini`，在 `-vmargs` **之前** 加 `-vm`：

```ini
-vm
D:\Java21\bin\javaw.exe

-vmargs
-Xmx4g
-XX:+UseG1GC
-Dfile.encoding=UTF-8
```

注意：

- `-vm` 和路径必须各占一行，且必须在 `-vmargs` 前面。
- 用 `javaw.exe` 而不是 `java.exe`，避免多一个控制台窗口。
- 16 GB 内存设置 `-Xmx4g` 足够。
- 如果启动报 `Java was started but returned exit code=13`，先检查 `-vm` 路径。

### 6.5 工作空间与启动脚本

工作空间：`D:\eclipse-workspace\rcp-learn`

启动脚本：`D:\tools\start-eclipse-rcp.cmd`

```bat
@echo off
start "" "D:\eclipse\rcp-2026-06\eclipse.exe" -data "D:\eclipse-workspace\rcp-learn"
```

首次启动后设置：

1. `Window > Preferences > General > Workspace`
   - Text file encoding：UTF-8
2. `Window > Preferences > Java > Installed JREs`
   - 添加 `D:\Java21`（JDK）
   - 添加 `D:\Java17\jdk-17.0.10`（JDK）
   - 默认勾选 JDK 21
3. `Window > Preferences > Java > Installed JREs > Execution Environments`
   - `JavaSE-21` → JDK 21
   - `JavaSE-17` → JDK 17
4. `Window > Preferences > Java > Compiler`
   - 新建 RCP 项目 compliance 21
5. `Window > Preferences > Maven > User Settings`
   - 指向 `C:\Users\薰\.m2\settings.xml`
6. `Window > Preferences > Git > Configuration`
   - 配置 `user.name`、`user.email`
7. `Window > Preferences > Install/Update > Available Software Sites`
   - 确认有 `https://download.eclipse.org/releases/2026-06`
8. 打开 `Window > Perspective > Open Perspective > Plug-in Development`

### 6.6 Maven 配置

**settings.xml**（`C:\Users\薰\.m2\settings.xml`，本次已创建）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.2.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.2.0 https://maven.apache.org/xsd/settings-1.2.0.xsd">
  <!-- 保留默认本地仓库，避免已有项目重复下载 -->
  <!-- <localRepository>D:\Maven\repository</localRepository> -->

  <mirrors>
    <mirror>
      <id>aliyun</id>
      <name>Aliyun Public</name>
      <url>https://maven.aliyun.com/repository/public</url>
      <mirrorOf>central</mirrorOf>
    </mirror>
  </mirrors>
</settings>
```

**toolchains.xml**（`C:\Users\薰\.m2\toolchains.xml`，本次已创建）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<toolchains>
  <toolchain>
    <type>jdk</type>
    <provides><version>21</version></provides>
    <configuration><jdkHome>D:\Java21</jdkHome></configuration>
  </toolchain>
  <toolchain>
    <type>jdk</type>
    <provides><version>17</version></provides>
    <configuration><jdkHome>D:\Java17\jdk-17.0.10</jdkHome></configuration>
  </toolchain>
</toolchains>
```

**mvn21.cmd**（`D:\tools\mvn21.cmd`，本次已创建）：

```bat
@echo off
setlocal
set "JAVA_HOME=D:\Java21"
call "D:\Maven\apache-maven-3.9.8\bin\mvn.cmd" %*
endlocal
```

验证：

```powershell
D:\tools\mvn21.cmd -v
```

输出中的 `Java version` 应为 21。

> Tycho 的依赖主要来自 p2 更新站点，Maven 镜像只加速 Maven 构件。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报 `exit code=13` | `-vm` 路径错误或指向 JRE | 改成 `D:\Java21\bin\javaw.exe`，确认路径存在 |
| 新终端 `java` 是 17 | 系统 PATH 中 Oracle javapath 优先 | 用 `D:\Java21\bin\java` 或 `mvn21`；必要时管理员调整 PATH |
| `mvn -v` 不是 21 | 全局 `JAVA_HOME` 仍是 17 | 用 `mvn21`，或临时 `set JAVA_HOME=D:\Java21` |
| 新插件无法解析 `org.eclipse.e4.*` | 目标平台未设置/缺 e4 feature | 设置 Target Platform；产品依赖加入 `org.eclipse.e4.rcp` |
| 找不到 `javax.inject` | 新版 Eclipse 已改用 Jakarta | 使用 `jakarta.inject`、`jakarta.annotation` |
| `Invalid thread access` | 非 UI 线程操作控件 | 用 `Display.getDefault().asyncExec(...)` |
| 中文乱码 | 工作空间/产品编码不一致 | 工作空间设 UTF-8；产品启动参数加 `-Dfile.encoding=UTF-8` |
| 产品导出缺插件 | Product 依赖的 feature 不全 | 在 `.product` 的 Dependencies 中加入 `org.eclipse.e4.rcp` 等 |
| Eclipse 启动/保存很慢 | 杀毒软件实时扫描 | 将 `D:\eclipse`、`D:\eclipse-workspace` 加入 Defender 排除项 |
| 工作空间异常 | `.metadata` 损坏 | 备份后新建工作空间，不要直接删源码 |
| EGit 提示 `HOME is not set` | Windows 未设置 HOME | 设置用户级 `HOME=C:\Users\薰`，重启 Eclipse |
